# Nova Studio — Business Landing Page

A polished, responsive business landing page created as a front-end portfolio project.

## Tech Stack
- HTML5
- CSS3
- Bootstrap 5
- Vanilla JavaScript
- Google Fonts

## Features
- Responsive navigation
- Modern hero section
- Animated visual/orbit
- Services section
- Selected work / case studies
- Company metrics
- Testimonial section
- Contact form with JavaScript feedback
- Mobile, tablet and desktop layouts

## Run
Open `index.html` in a browser.

## Portfolio note
Nova Studio and all company names shown on the page are fictional and used for demonstration purposes.
